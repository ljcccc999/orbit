# Orbit 2.0.0

Orbit 2.0 turns the local training studio into a complete AI workspace.

- Train, continue training and fine-tune your own Orbit models.
- Use one ordered library for local and API models across Orbit and Orbit Code.
- Run Orbit Code with planning, live activity, guidance, approvals, tools and verification.
- Expand execution from phase summaries to tool output, red/green diffs and full-file preview.
- Review per-file changes and use conflict-checked undo with confirmation.
- Reuse one automatic Orbit workspace, with Ask, Auto approve and Full access modes.
- Search the web and files, attach images/audio, use voice input and optional computer control.
- Keep local context, inspectable long-term memory, separate histories, plugins and reviewed collaboration.
- Close the window while the local Agent/API continues; explicitly quit Orbit to stop the service.
- Refined desktop UI with SF Pro/PingFang, frosted glass, liquid controls, concentric squircle geometry and reduced-motion support.

Validation: 67 automated tests, Python compilation, generated JavaScript syntax, diff checks and a real low-cost Orbit Code/API workflow passed on macOS. Windows and Linux artifacts are cloud-built and require platform-specific installation testing.

## 中文

Orbit 2.0 把本地训练工作室升级为完整 AI 工作空间。

- 训练、继续训练和微调自己的 Orbit 模型。
- Orbit 与 Orbit Code 共用一套本地/API 模型库和默认模型。
- Orbit Code 支持计划、实时状态、引导、批准、工具执行和验证。
- 执行过程可从阶段汇总展开到工具输出、红绿 Diff 和完整文件预览。
- 按文件审核修改，并在确认后执行带冲突检查的撤销。
- 默认复用一个 Orbit 工作区，提供请求批准、替我批准和完全访问。
- 支持网页/文件搜索、图片与音频附件、语音输入和可选鼠标键盘控制。
- 支持本地上下文、可查看长期记忆、分模式历史、插件与审核制协作。
- 关闭窗口时本地 Agent/API 继续运行，明确退出 Orbit 才停止服务。
- 桌面界面统一 SF Pro/苹方、毛玻璃、液态玻璃、同心连续圆角和减少动效。

验证：macOS 上 67 项自动测试、Python 编译、生成 JavaScript 语法、差异检查和真实低成本 Orbit Code/API 流程通过；Windows/Linux 安装包由云端构建，仍需对应真实平台安装验证。
