# Orbit 2.0.1

## 中文

- 修复批准操作后 Orbit Code 停在等待状态的问题；批准会可靠唤醒并继续当前任务。
- 修复执行过程中无法向上查看历史问题的问题；只有停留在底部时才自动跟随最新进度。
- 执行进度圆改为完整闭环，不再显示缺口。
- 智能滑杆不再拖动 App 窗口；滑块为正圆，轨道为椭圆形液态玻璃。
- 修复左侧“新对话”入口无响应；Orbit 与 Orbit Code 会在各自产品中创建新对话。
- 执行完成后默认收起过程，第一层显示“已耗时”并可展开；中间过程按“阶段说明 → 工具汇总 → 下一阶段说明”交错呈现，普通执行文字不再堆叠多层卡片。

## English

- Approval now reliably wakes Orbit Code and resumes the pending action.
- Live updates preserve the reader's scroll position unless they are already following the bottom.
- The execution progress ring is now a closed circle.
- The intelligence control no longer drags the app window; it uses a circular thumb and pill-shaped glass track.
- The sidebar New Chat action now creates a conversation in the active Orbit product.
- Completed execution details collapse by default into an expandable “Ran for” row, with flatter activity presentation.
