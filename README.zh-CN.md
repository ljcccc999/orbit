# Orbit 2.0

Orbit 是 YUNSH 的本地 AI 工作空间：训练自己的模型、在本机运行模型，并让 Agent 把一个问题真正执行、验证和交付。

## 重要功能

- **训练自己的模型** — 从零预训练、继续训练，或微调兼容的 Orbit checkpoint；支持人工语料与教师 AI 辅助数据。
- **统一模型库** — 本地模型与主流/自定义 OpenAI 兼容 API 模型集中管理，可改名、排序、加载和卸载；第一项同时作为 Orbit 与 Orbit Code 的默认模型。
- **Orbit Code Agent** — 先说明计划，再执行；工作中报告新发现，可搜索网页和文件、修改代码、运行命令、验证结果，最后给出简洁总结。
- **执行过程可查看** — 显示正在思考、搜索、编辑或运行，工具调用可展开，并提供用时、步骤进度，以及“活动 → 差异 → 完整文件预览”的三层查看。
- **修改可审核** — 新增为绿色、删除为红色，显示文件和行数；完成回答下方提供修改卡片、筛选审核，以及需要确认且检查冲突的安全撤销。
- **不中断的引导** — 执行中发送的消息默认排队并显示在输入栏上方；需要时可提升为立即引导。排队消息删除前确认，已经消费的引导不可撤销。
- **工作区与权限** — 默认复用一个 Orbit 工作区，也可选择项目目录；提供请求批准、替我批准、完全访问三档，以及独立的鼠标键盘控制权限。
- **本地上下文与长期记忆** — 可选项目上下文和本地长期记忆；稳定信息可自动或手动写入、查看和删除，并自动清除敏感信息。
- **文件、图片和语音** — 支持图片/音频附件、语音输入，以及在对话右侧预览生成或修改后的完整文件。
- **后台本机服务** — 关闭窗口时轻量 Agent 与 OpenAI 兼容 API 继续运行；明确退出 Orbit 时才同时停止。
- **协作与插件** — 审核制贡献包、可选 Orbit Hub 流程和本地插件；插件仍受同一权限边界约束。

## 三种模式

- **Orbit** — 本地/API 对话、历史、记忆和统一模型库。
- **训练** — 数据、预训练、微调、checkpoint、本地模型操作和协作。
- **Orbit Code** — 项目执行、过程历史、批准、差异、文件审核和电脑操作。

三种模式分别显示自己的历史记录和固定入口。macOS 界面采用 SF Pro/苹方字体、克制的半透明毛玻璃侧栏、液态玻璃控件、同心 iPhone 式圆角，并支持减少动效。

## 本机 API

Orbit 在 `127.0.0.1` 提供 OpenAI 兼容本机 API，支持 `/v1/chat/completions` 与 `/v1/responses`。训练数据、checkpoint、对话、配置和记忆默认只保存在本机。

## 平台安装包

Orbit 2.0 面向 macOS、Windows x64/ARM64 和 Linux x64/ARM64。每个 GitHub Release 会列出实际通过的平台验证与可下载资产。

## 架构与研究

- **orbit-hybrid-moe-v1** — Orbit 的实验性字节级混合 MoE 架构。
- **OCA（Orbit Continuum Architecture）** — 面向持续世界模型的研究方向，不作为已经交付的能力宣传。
