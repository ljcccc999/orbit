# OCA 项目文档

> 归属：独立 Orbit 项目的底层模型架构研究
> 状态：未实现完成，不能作为已具备物理世界理解能力的模型

## 1. 项目卡片

| 项目项 | 内容 |
| --- | --- |
| 架构名称 | OCA（Orbit Continuum Architecture） |
| 项目归属 | Orbit 底层模型架构，与 `orbit-hybrid-moe-v1` 并列 |
| 目录 | `/Users/tim/Desktop/YUNSH/Orbit/orbit/OCA-Research/` |

| 公开表述边界 | “目标成为行业首个理解物理世界的架构”，不是已验证事实 |

## 2. 架构方向

OCA 试图把观察、对象、时间、动作和未来状态作为显式变量，而不是只依靠
普通语言模型的下一个 token 预测隐式记忆：

```text
观察
  → 感知
  → 对象槽位绑定
  → 持久连续状态
  → 动作条件状态转移
  → 多步未来想象
  → 语言/动作输出
```

## 3. 未实现边界

当前 OCA 的代码、合成世界数据和结构配置只能证明部分研究链路可以运行，
不能证明它已经理解真实物理世界。尚未完成的验证包括真实物理基准、参数
匹配基线、未见对象/动作泛化、长时状态稳定性、消融实验和第三方复现。

OCA 不属于当前桌面 Orbit 的普通聊天运行时，不与
`orbit-hybrid-moe-v1` 混用模型权重、训练记录、参数或质量结论。
